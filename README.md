# VA Wellness

An original Shopify theme for wellness and healthcare storefronts. Inspired by calm, modern health-and-mindfulness layouts — built from scratch on Shopify’s Skeleton architecture (not a copy of any paid Theme Store theme).

## Preview

```bash
shopify theme dev --store your-store.myshopify.com
```

## Included

- Sticky header + announcement bar
- Full-bleed hero, featured collection, promo tiles
- Trust badges, image with text, FAQ, newsletter
- Product page with tabs and quick-add cards
- Collection grid and cart with notes

## Customize

Use the theme editor to assign collections, upload hero/promo images, and adjust colors under **Theme settings**.
